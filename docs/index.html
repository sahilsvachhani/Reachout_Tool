One-time Setup
MailBlast uses the Gmail API to send emails from your Google account. You need a free Google OAuth Client ID to connect it. Here's how to get one in ~2 minutes:
1
Go to Google Cloud Console → create a new project (or select one).
2
Go to APIs & Services → Enable APIs → enable the Gmail API.
3
Go to APIs & Services → Credentials → Create Credentials → OAuth Client ID. Choose Web application.
4
Under Authorised JavaScript origins add:
5
Copy the Client ID and paste it below.
